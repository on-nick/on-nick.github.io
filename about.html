Profile

I'm a B.Sc. CSIT student at Bhairahawa Multiple Campus, currently pursuing my degree while building practical experience in cybersecurity outside the classroom. My interest in the field started with networking fundamentals — understanding how systems actually communicate — and grew into a focus on where that communication breaks down or gets misused.

Since January 2022, I've worked independently as a security researcher and bug hunter, conducting reconnaissance and security assessments on web applications and infrastructure within authorized program scopes. I spend most of my time on web application security, network security, and Python-based security automation — building small tools that make reconnaissance, log analysis, and testing workflows faster and more repeatable.

I'm still early in this path. I don't overstate what I've done — the work below reflects where I actually am: a student researcher building real skills through authorized testing, self-directed labs, and continuous learning.
